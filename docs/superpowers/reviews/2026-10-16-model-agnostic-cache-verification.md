# 通用模型缓存模拟验证

日期：2026-10-16；实现基于 `0af5f21`，设计提交 `9cc5c33`。

## 已确认的行为

- `prefix_total` 对任何非空实际上游模型标识使用同一模拟规则，不依赖家族、版本或静态模型名单。
- 模型发现与权限继续由上游列表、既有账号路由和实际成功结果决定；列表为空时不阻止一个成功调用的新模型参与模拟。上游拒绝和账号无权限时没有成功计费结果、缓存提交或成功诊断记录。
- 保留旧 Claude 数字名称的点/横杠及包装前缀兼容；其他模型保留标点、路径和供应商前缀，防止不同标识共享指纹。配置别名使用已有路由后的模型。
- 后台比例、成功写入、有效期读取、增量创建、原生计数校准、TTL 拆分及旧模式语义不变。0% Key 独立覆盖全局，且不生成隐藏缓存。
- 诊断规则为 `prefix-total-v4`，空标识使用 `empty_model`；说明明确为本地模拟。
